# AegisThread

Status: Specification (draft for human review)
Date: 2026-10-24

AegisThread is a Symfony/PHP application for privacy-conscious,
retrieval-based AI assistance. The project is in the specification phase:
the documentation below defines what will be built; no implementation
exists yet.
